⚙️ 구글 스프레드시트 연동 설정

구글 스프레드시트의 [확장 프로그램] > [Apps Script]에서 code.gs 코드를 배포한 후 발급받은 웹 앱 URL을 입력하세요.
💡 연동 가이드 요약 (상세 내용은 setup.md 참고)
  1. 스프레드시트에 '도서목록', '대여기록' 탭 준비
  2. [확장 프로그램] > [Apps Script]에 code.gs 붙여넣기
  3. [배포] > [새 배포] > [웹 앱] 선택
  4. 액세스 권한: '모든 사용자(Anyone)'로 설정 필수!
  5. 생성된 웹 앱 URL을 위에 입력하고 저장 버튼 클릭
